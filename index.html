▶ Github上にバックアップするプログラム！
ソースコードダウンロードリンク
▶ 初期準備
▶ 1：Gitのインストール 
winget install --id Git.Git -e --source winget
上記のコードをpowershellで実行してください。
ライセンスへの同意などが求められた場合はしっかり読んでください。

これでGitコマンドが入ったと考えます。分からなかった場合は各自で調べてみてください。
▶ 2：Pythonのインストールとライブラリのインストール
次にPythonをダウンロードします。
ダウンロード方法などは各自調べてください。
次に以下のコマンドをpowershellで実行してください。
pip install requests
もし、Pythonを入れた直後の場合はpowershellを再起動してください。
▶ 3：Gitの初期設定
次にgitの初期設定をします
以下のコマンドをpowershellで実行してください。
git config --global user.name "あなたの名前"
git config --global user.email "あなたのメールアドレス"
これで初期設定は終わりです。
ですが、実行するための必要項目はまだあります。
▶ コード実行
▶ 1：初期設定
以下のPythonコードの部分は変更してください。
OWNER = "{Githubアカウント名}"
REPO = "{Github基準リポ名}"
TARGET_FOLDER = r"{バックアップする基準フォルダ}"
#--- 以下例 ---#
EXT_JSON = r"C:\Projects\バックアップ機能\data\extensions.json"
EXCLUDE_JSON = r"C:\Projects\バックアップ機能\data\exclude.json"
REPOS_JSON = r"C:\Projects\バックアップ機能\data\repos.json"
ZIPS_JSON = r"C:\Projects\バックアップ機能\data\zips.json"
REPO_LIST_TXT = r"C:\Projects\バックアップ機能\data\repo_list.txt"
HASH_CACHE_JSON = r"C:\Projects\バックアップ機能\data\hash_cache.json"
TEMP_BASE = r"C:\temp\BackupTemp"
▶ 2：各選択肢の意味
基本は名前のままです。
▶ 1
一番よく使うと思います。
実際のアップロード処理が開始されます。
これを実行するとGithub上にバックアップされる、ぐらいのイメージでいいです。
１番のみ引数で--1をつけると自動で選択肢を1で実行してくれます。
※拡張子フィルタが反映されるので、3番で拡張子を設定しておく必要があります。
※除外フォルダで選択されたもの、ZIPフォルダ登録、別リポ登録をしたフォルダは自動で除外されます
▶ 2
登録している拡張子一覧を教えてくれます。
▶ 3
拡張子を追加できます。
拡張子を追加しないと何もGithub上に上げられません。
入力形式は
.○○
という形です。
▶ 4
拡張子を削除できます。
▶ 5
除外フォルダ一覧です。
▶ 6
除外フォルダ追加です。
除外フォルダの用途としては、保存内に余計なものがあるが、それを含めたくない、などです。
ZIP登録や別リポに登録されていても、ここで登録すると強制除外となります。
▶ 7
除外フォルダ削除です。
▶ 8
別リポ一覧です。
▶ 9
別リポ追加です。ここではどのフォルダを別リポに設定するか、を選択します。
別リポの記述は"REPO_LIST_TXT"変数で指定したテキストファイルに箇条書きでリポジトリ名を書いていきます。
backup_repo1
backup_repo2
backup_repo3
▶ 10
別リポ削除です。
▶ 11
終了です。プログラムが止まります。
基本的に入力欄で"cancel"と打つ事でも止まります。
▶ 12
ZIPにすると登録したフォルダ一覧です。
▶ 13
フォルダをZIPに登録できます。
想定としてはUnityのプロジェクトフォルダを指定したりなどです。
▶ 14
ZIPに指定したフォルダを削除できます。

▶ CherryTreeのHTML出力を自分の好きな形に変えよう！
ソースコード・HTMLダウンロードリンク
▶ 以下は動画で紹介していないexeバージョンについてです
exe版ダウンロードリンク
zipがダウンロードされると思うので、中身を解凍し使う場合は「output_html.exe」をクリックしてください。
ファイル選択ダイアログが開いて、その後にフォルダ選択ダイアログが開きます。
ファイル選択ではCherryTreeから出力したテキストファイルを選択してください。
フォルダ選択ではどこにhtmlを出力するかです。同じフォルダにoutput.htmlがあった場合は上書きされるので注意してください。
sourceフォルダ内にはソースコードが入っています。そちらから実行しても挙動は同じです。
